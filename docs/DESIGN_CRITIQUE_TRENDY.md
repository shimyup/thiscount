# Thiscount 디자인 크리틱 — 직관·가시성·트렌디 (2026-06-04)

> /design-critique 프레임워크 적용. 다크테마 Flutter. 참조: 토스·당근·Pokémon GO·
> Duolingo·캐시워크. 스크린샷 기반(시뮬레이터 iPhone17). 우선순위 🔴Critical/🟡Mod/🟢Minor.

## 종합 인상
기능은 성숙(반경원·나침반·만료배너·밝기부스트 다 있음)하나, **화면이 정보 막대(bar)
스택으로 빽빽**하고 **콘텐츠 카드가 비어 보여** "한눈에" 들어오지 않음. 트렌디 앱들의
공통점(여백·큰 타이포·썸네일 카드·단일 히어로 지표)을 적용하면 체감 품질이 크게 오름.

---

## 1. 수집첩(인박스)
**첫인상**: 상단에 제목·정렬·검색·지갑뱃지 → 진행바(9/50) → 초록 팁배너 → 빨강 만료배너
→ "새 혜택 9" → 받은/보낸 토글 → 필터칩 → 그제서야 letter. **막대 6개 후 콘텐츠** = 인지 부하.

| 발견 | 심각 | 추천 |
|---|---|---|
| letter 카드가 색 그라데이션 블록 + 작은 코드 아이콘뿐, **매장명·혜택·만료 안 보임** | 🔴 | 당근식 카드: [업종 이모지 + 매장명/제목] · [혜택 굵게 "1+1"] · [만료 D-2 배지] · [코드칩]. 카드가 스스로 설명되게 |
| 상단 막대 과다(팁/만료/카운트/진행바) | 🟡 | 만료 사이렌만 상단 1개 유지, 팁배너·"새 혜택 N"은 제거/통합. 진행바는 작게 헤더에 흡수 |
| 필터칩 가로 넘침("쇼핑" 잘림) | 🟢 | 가로 스크롤 + fade edge(이미 ellipsis 적용). 또는 칩 수 축소 |

## 2. 프로필
**첫인상**: 아바타 위에 "프로필"(축소 타이틀)이 **겹쳐 깨져 보임**. 지표가 상단 4-stat +
"나의 카운터 기록" 두 곳에 분산.

| 발견 | 심각 | 추천 |
|---|---|---|
| SliverAppBar 축소 타이틀 "프로필" 이 펼친 아바타와 겹침 | 🔴 | collapse 전엔 타이틀 숨기고(opacity), 아바타 영역과 분리 |
| 지표 분산(4-stat ↔ 카운터기록 중복: 받은≈픽업) | 🟡 | 토스식 단일 "이번 달 활동" 카드: 큰 숫자(픽업) + 보조 grid(사용·연속일·방문). 4-stat 바 흡수 |
| 카드 4~5개 평면 나열, 저대비 | 🟡 | 카드 2~3개로, 히어로(아바타+이름+티어+🔥연속일) 1블록, 레벨 진행바 1개 |
| ✅ 비-Brand '보낸 0' → 🔥연속일 (Build 433 적용) | — | 완료 |

## 3. 지도(탐험)
**첫인상**: 첫 진입에 리워드 시트가 자동 오픈되는데 **이미지 깨짐 플레이스홀더** 노출.

| 발견 | 심각 | 추천 |
|---|---|---|
| 샘플/이미지 없는 letter 시트의 broken-image 아이콘 | 🟡 | 이미지 없으면 업종 이모지 + 브랜드 컬러 그라데이션 플레이스홀더(깨진 아이콘 금지) |
| 마커 가시성 | 🟢 | 도착 이모지 업종별 적용됨(Build 433). rare/epic 글로우 유지 — 좋음 |

## 4. Premium 페이월
**첫인상**: 비교 카드 깔끔(반경/쿨다운/DM/커스텀). 트렌디 측면 양호.
- 🟢 추천: Free 200m vs Premium 1km **반경을 지도 원 2개로** 시각화하면 전환력↑(토스/Duolingo Super식 비주얼 셀링).

## 5. 온보딩
- 🟢 국가선택 화면 깔끔(여백·리스트카드 좋음). 투어 제거(Build 433)로 진입 단축됨 — 좋음.

## 트렌디 디자인 토큰 방향 (전역)
- **여백 +20%**: 카드 간 간격·내부 padding 키워 숨 쉬게(토스/당근 공통).
- **타이포 스케일 강화**: 핵심 숫자 28→32pt, 라벨 uppercase 10→11pt. 위계 또렷이.
- **카드 그림자/라운드 일관**: soft shadow(0,4,16 / black 0.25) + radius 20 통일. 현재 평면 카드 → 입체감.
- **액센트 절제**: gold/teal/coupon 3색 역할 고정(gold=premium, teal=free/긍정, coupon=brand/긴급). 남용 자제.
- **마이크로 인터랙션**: 탭 scale 0.97, 줍기 confetti(있음), 탭 전환 fade.
- **빈 상태**: 일러스트 + 단일 CTA(Duolingo). 현재 텍스트 위주.

## 즉시 적용 가능한 안전 수정 (제안 — 승인 시 구현)
1. 🔴 프로필 아바타-타이틀 겹침 수정 (SliverAppBar collapse opacity)
2. 🔴 인박스 letter 카드 자기설명화 (업종 이모지+제목+혜택+만료 배지)
3. 🟡 깨진 이미지 → 업종 이모지 플레이스홀더 (전역 letter 이미지)
4. 🟡 프로필 지표 단일 "이번 달 활동" 카드 통합
5. 🟢 Premium 반경 비교 비주얼

> 2·4 는 레이아웃 변경폭이 커서 시뮬레이터 시각검증과 함께 진행 권장.
