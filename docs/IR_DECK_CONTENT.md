## 2) 한 줄 정의 (What is Thiscount)
- **헤드라인**: "포켓몬 고처럼 줍는 쿠폰"
- 사용자는 지도 위 내 주변 200m 안에 떨어진 브랜드 혜택(할인권·교환권)을 **걸어가서 줍고**, 매장에서 **바로 사용**합니다.
- 브랜드는 자기 매장 반경에 쿠폰을 **자동으로 뿌리고(zone)**, 실시간으로 ROI를 측정합니다.
- 캡션: 감성(발견의 재미) × 실용(즉시 사용 가능한 할인)

## 3) 문제 (Problem)
- **헤드라인**: 쿠폰은 넘치는데, 아무도 안 줍는다
- 소비자: 쿠폰 앱은 "검색·필터·스팸 푸시" 피로 → 발견의 재미 없음, 사용률 낮음
- 오프라인 매장: 전단지·배달앱 광고는 **누가 봤는지·왔는지 측정 불가**, 비싸고 일회성
- 관광/로컬: 외국인·신규 방문객이 **내 주변 실시간 혜택**을 찾을 채널이 없음
- 캡션: "노출"은 팔지만 "방문"은 못 파는 광고 시장

## 4) 솔루션 (Solution)
- **헤드라인**: 위치 + 게임 = 실제 매장 방문
- **줍는 재미**: 지도 위 발견·희귀도(레어/에픽)·레벨·연속출석으로 리텐션
- **즉시 전환**: 주운 쿠폰은 매장 POS 코드로 바로 사용 → 오프라인 방문 직결
- **측정 가능**: 브랜드는 발송→픽업→노출→사용 **퍼널을 실시간 대시보드**로 확인
- 캡션: 광고비를 "방문·사용"이라는 결과로 전환

## 5) 작동 방식 (How it works)
- **3단계 도식**:
  1. 브랜드가 쿠폰 발송/매장 zone 설정 (AI가 카피 자동 생성)
  2. 사용자가 지도에서 발견 → 200m 안으로 걸어가 픽업
  3. 매장에서 코드 제시 → 사용 → 브랜드 ROI에 집계
- 캡션: 발송 → 픽업 → 사용까지 한 흐름

## 6) 제품 핵심 기능 (Product)
- **사용자(헌터)**: 지도 픽업 · 희귀 드롭 · 레벨/타워 성장 · 수집첩 · 팔로우/DM
- **브랜드**: 매장 zone 자동 발송 · ExactDrop(정밀 투하) · 1캠페인=1코드 POS · ROI 퍼널 대시보드
- **AI**: 업종·설명 입력 → 쿠폰 카피·혜택 초안 자동 생성(온보딩 마찰 제거)
- **글로벌**: 14개 언어(아랍어 RTL 포함), 국가별 현지화
- 캡션: 양면 시장(소비자·매장)을 한 앱에서

## 7) 차별점 / 해자 (Why us / Moat)
- **발견형 UX**: 검색형 쿠폰앱과 다른 "줍는" 경험 → 높은 인게이지먼트
- **오프라인 전환 측정**: 픽업·사용 데이터로 "방문 단가" 광고 상품화 (전단지/배달광고가 못 하는 것)
- **AI 온보딩**: 매장이 30초 만에 캠페인 생성 → 공급(쿠폰) 확보 속도
- **게이미피케이션 리텐션**: 레벨·희귀도·스트릭으로 재방문 동기
- 캡션: 데이터가 쌓일수록 추천·매칭 정확도 강화(네트워크 효과)

## 8) 시장 (Market)

## 9) 수익 모델 (Business Model)

- **확장**: AI 쿠폰 생성 프리미엄 · 데이터/인사이트 · 관광청·프랜차이즈 제휴
- 캡션: 양면 수익 — 소비자 구독 + 매장 성과형 광고
