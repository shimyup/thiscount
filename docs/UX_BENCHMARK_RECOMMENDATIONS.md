# Thiscount UI/UX 개선 방향 — 타 앱 벤치마크 (2026-06-04)

> 위치기반 쿠폰 줍기 + 게임화 + 3티어(Free/Premium 줍기 · Brand 발송) 구조 기준.
> 각 항목은 **참조 앱 → 적용 아이디어 → Thiscount 화면/파일**로 매핑. 우선순위 표기.

## 참조 앱 풀
- **Pokémon GO / Niantic** — 위치 발견, 근접 마커, 반경, 도착 보상, nearby 레이더, 첫 캐치 튜토리얼
- **당근마켓(Karrot)** — 하이퍼로컬, 깔끔한 3탭, 동네 피드, 한국형 단순 UX
- **토스(Toss)** — 카드형 초미니멀 UI, 큰 친근한 숫자, 마이크로 인터랙션, 단일 CTA
- **캐시워크/토스 만보기** — 걷기-적립 수집 게임화, 일일 engagement loop, 코인 줍기 쾌감
- **스타벅스 / 카카오 선물하기** — 쿠폰 지갑, 만료 카운트다운, POS 바코드/코드 reveal(전체 밝기)
- **RetailMeNot / Honey** — 쿠폰 리스트, '곧 만료' 긴급 섹션, 원탭 코드 복사
- **Foursquare Swarm / 지오캐싱** — 체크인, 나침반/거리, 스티커·스트릭
- **Duolingo** — 스트릭/XP, 마일스톤 축하, 친근한 빈 상태, 짧은 온보딩
- **Meta Ads / 네이버 스마트플레이스** — 광고주 퍼널 대시보드(Brand 화면)

## 빠른 실행 후보 — 실제 구현 상태 (2026-06-04 코드 검증)
> ⚠️ 코드 확인 결과 대부분 **이미 구현돼 있었음**. 문서 초안이 과소평가.
1. ✅ **지도 사용자 반경 원** — `world_map_screen.dart:408` CircleLayer(tier 색) **이미 구현**. Build 429: Brand 는 픽업 불가라 링 숨김 처리 추가.
2. ✅ **근접 방향/거리 힌트** — `_nearestLetterCompass` + `mapCompassHint` 배너 (반경 비었을 때 방향·거리) **이미 구현**.
3. ✅ **코드 reveal 화면 밝기 부스트** — `letter_read_screen.dart:3493` `setApplicationScreenBrightness(1.0)` + 복원 **이미 구현**.
4. ✅ **'곧 만료' 배너** — `inbox_screen.dart` 만료 사이렌(24h, 탭→쿠폰필터) **이미 구현**.
5. ⏳ **권한 요청 지연 + 온보딩 단축** — 미적용. 온보딩(투어3+인트로5+Premium)은 사용자가 직접 큐레이션 → 어느 화면을 줄일지 **사용자 결정 필요**. 권한은 이미 main() startup + 온보딩 GPS 페이지 양쪽 → 중복 정리 검토 가능.

## 프로필 탭 "한눈에 안 들어옴" 개선 (2026-06-04 device)
> 참조: 토스 마이페이지, 당근 프로필, Duolingo 프로필(스트릭 중심), 캐시워크 홈.
> 현재: 4-stat 바(보낸/받은/방문/팔로워) + 오두막 카드 + '나의 카운터 기록'(이번달
> 픽업·사용/누적) + 줍기 반경 — **지표가 두 곳(상단 바 + 카운터 기록)에 분산**돼 스캔 어려움.

**적용한 빠른 개선 (Build 433)**
- ✅ 비-Brand 4-stat 첫 항목 '보낸(항상 0)' → 🔥 **연속일(streak)** 로 교체(리텐션 지표·노이즈 제거).

**추가 추천 (제안)**
1. **지표 통합** (토스): 상단 4-stat 바와 '나의 카운터 기록'이 중복(받은≈픽업) → 단일 "이번 달 활동" 카드로 통합. 큰 숫자 1개(이번 달 픽업) + 보조 grid(사용 완료·연속일·방문국).
2. **히어로 영역 강화** (Duolingo): 아바타+이름+티어 배지+🔥연속일 을 한 블록으로 묶어 최상단 — 정체성 즉시 인지.
3. **레벨/타워는 진행바 1개로** (캐시워크): '오두막' 카드를 레벨 진행바(현 레벨 → 다음 레벨 %)로 시각화, 탭 시 상세.
4. **카드 수 축소**: 현재 카드 4~5개 세로 나열 → 2~3개로(활동 통합 + 레벨 + 구독). 여백·그림자 일관(디자인 토큰).
5. **Brand 프로필 분기**: Brand 는 '보낸/캠페인·ROI 요약' 중심, 일반은 '줍기·연속일' 중심으로 상단 지표 다르게.
