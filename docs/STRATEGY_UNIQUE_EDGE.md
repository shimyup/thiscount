# Thiscount 전략 분석 & 유니크 강점 (Build 453)

## 1. 현재 포지션
"포켓몬GO식 쿠폰 헌팅 × 매장 캠페인 도구"
- 유저: 반경 줍기(200m/1km) · 쿨다운 · 레어드롭(rare/epic) · 스트릭 · 수집첩 · 편지 여행 메타포
- 매장(Brand): 단건/대량/자동발송 zone · 할인코드(POS 등록 1회, 설치 0) · ROI 퍼널 · AI 쿠폰 생성
- 수익: Free / Premium(₩4,900) / Brand 3-tier

## 2. 구조적 공백 (성공을 막는 것)
1. **루프가 1회성** — 줍기→사용→끝. 같은 매장 재방문 동기 없음.
   사장이 돈 내는 진짜 이유 = **단골**인데, 측정도 보상도 없었음.
2. 양면시장 콜드스타트 (매장↔유저 동시 필요)
3. DM 로컬 시뮬(가짜) / anon-auth 구조 부채(Phase 3 진행 중)

## 3. 경쟁 지형
| 경쟁자 | 가진 것 | 없는 것 |
|---|---|---|
| 당근마켓 | 동네 트래픽·노출 광고 | 게임화, 재방문 루프 |
| 네이버 플레이스 | 검색·예약 | 푸시 발송, 헌팅 |
| 도도포인트/스탬피 | 매장 스탬프 | 디스커버리(신규 유입), 태블릿 필요 |
| 캐시워크 | 걷기 보상 | 매장 연결 |

→ **"발견→방문→재방문" 풀퍼널을 가진 플레이어가 없음.**

## 4. 결정: 유니크 강점 = 단골 스탬프 (Build 453 구현됨)
- 같은 매장 쿠폰/교환권 사용 시 스탬프 +1 (general 홍보·보상쿠폰 자체·셀프리딤 제외)
- 5개 완성 → **보상 쿠폰(epic) 자동 발급**(인박스, 30일 기한, 매장 코드 재사용) + 완성 누적(🏆)
- 프로필에 매장별 스탬프 카드(●●●○○) / redeem 직후 골드 축하 스낵바
- 저장: user-scoped prefs — **서버 스키마/룰 변경 0**, 계정전환 누수 차단 포함
- 파일: `lib/models/brand_stamp.dart` · `lib/features/hunt_wallet/stamp_cards_row.dart` · app_state 훅

### 셀링 포인트 (매장 영업용 한 줄)
"당근 광고는 노출에서 끝나지만, Thiscount는 지나가던 사람을 단골로 만들어 줍니다."

## 5. 다음 레버 (우선순위 로드맵)
1. **브랜드 측 단골 지표** — ROI 대시보드에 "단골 전환" (Auth Phase 3 후 서버 집계 승격)
2. **스탬프 보상 커스텀** — 브랜드가 임계값/보상 직접 설정 (user doc 필드 + rules 화이트리스트)
3. **친구 쿠폰 선물** — 주운 쿠폰 딥링크 공유 → 양쪽 보상 (바이럴 루프, 콜드스타트 완화)
4. **브랜드 도감** — 카테고리/지역별 컬렉션 완성 배지 (수집 리텐션 심화)
5. **동네 핫스팟 히트맵** — 쿠폰 밀집 지역 시각화 (탐험 동기)

cross-device 동기화는 Auth Phase 3 (authUid owner-scope) 완료 후 user doc 승격.
