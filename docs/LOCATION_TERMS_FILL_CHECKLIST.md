# 위치기반서비스 이용약관 — Placeholder 채움 체크리스트

대상 파일: `docs/location_terms.html`
근거 법령: 「위치정보의 보호 및 이용 등에 관한 법률」(위치정보법) 제18조·제19조 필수기재사항

> ⚠️ 본 약관은 **초안(DRAFT)** 입니다. 아래 `[대괄호]` 값을 채운 뒤 **반드시 변호사 검토**를 거쳐 게시하십시오.
> HTML 주석에 `변호사 검토 필요` 가 달린 조항(제4조 관리책임자, 제10조 효력·변경)은 특히 주의.

## 3. 호스팅 안내 (GitHub Pages)

`thiscount-pages` 레포(GitHub Pages)에 `location_terms.html` 을 push 하면 다음 URL 로 서빙됩니다:

```
https://shimyup.github.io/thiscount-pages/location_terms.html        # 한국어(기본)
https://shimyup.github.io/thiscount-pages/location_terms.html?lang=en # 영어
```

push 후 위 URL 이 **HTTP 200** 으로 응답하는지 확인하세요(브라우저 또는 `curl -I <URL>`).
앱 내 링크(`AppLinks.locationTerms`)가 이 URL 을 가리키는지도 함께 점검.

> 참고: 앱 코드는 본 작업에서 변경하지 않았습니다(docs/ 한정). 링크 도메인 교체가 필요하면 별도 작업으로 진행하세요.
