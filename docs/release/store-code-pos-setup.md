# 매장 POS 코드 등록 가이드 — Brand 사장용

Thiscount 의 사용 코드 흐름을 매장 운영자가 1페이지로 이해할 수 있도록.

---

## 1. 사용 코드란?

손님이 letter 를 픽업하고 "사용 진행" 을 탭하면 letter 안에 발급된 **8자
영숫자 코드** (예 `TC-K7M2-J9PH`) 와 **Code128 바코드** 가 노출됩니다.

- 매장은 이 코드를 **본인 POS 시스템** (편의점/카페/소매 등에서 이미 쓰는 그
  POS) 의 "쿠폰" 또는 "직원 할인" 항목에 **1회 등록**하면 끝.
- 손님이 매장에서 폰을 보여주면 → POS 의 1D 바코드 스캐너로 스캔 또는 코드
  텍스트 입력 → 자동 할인 적용.

---

## 2. 운영 흐름

```
Brand (앱)               손님 (앱)                 매장 (기존 POS)
──────────               ────────                  ──────────────
1) compose 에서          (letter 픽업)
   "🛒 사용 코드 발급"
   토글 ON 후 발송
   ↓
2) 발송 직후 dialog 로
   코드 노출 (예
   "TC-K7M2-J9PH")
   ↓
3) POS 에 1회 등록:
   - "쿠폰 코드" 항목
   - 코드: TC-K7M2-J9PH
   - 할인율: 20% (예)
   - 만료: 일치하게
                          (며칠 후 매장 도착)
                          "사용 진행" 탭
                          ↓
                          코드 + 바코드 reveal
                          ↓ (2h 안)
                                                  1D 바코드 스캐너로 스캔
                                                  → 할인 자동 적용
                          ↓
                          "사용 완료" 탭
                          (2h 지나면 자동)
```

## 3. 자주 묻는 질문

### Q1. 한 캠페인을 100명에게 보냈는데, 코드는 1개인가요?
✅ 네. **캠페인 1개 = 코드 1개**. 100명 모두 같은 코드를 받습니다. 매장은 POS
등록 1회로 끝.

### Q2. 매장 POS 가 "이미 사용된 코드" 라고 거절하지 않나요?
대부분의 POS 는 **할인 코드를 반복 적용 가능한 설정**이 있습니다 (멤버십 할인
유사). 등록 시 "1회용 ❌" / "재사용 가능 ✅" 옵션을 확인하세요.

만약 POS 가 1회용 강제면:
- "직원 할인" 코드 항목 사용 (보통 무제한)
- 또는 "이벤트 쿠폰" 코드 항목 사용

### Q3. 손님이 코드를 매장에 가지 않고 친구한테 알려주면?
세 가지 보호 장치가 있습니다:
1. 코드 reveal 자체는 letter **픽업한 사용자만** 가능 (IDOR 가드).
2. 한 letter 의 사용 완료는 **1회만** 기록 (해당 사용자 기준).
3. 매장에서 거절 시 다른 매장도 다 같은 코드라 어디서나 동일한 거절 메시지.

> 단, **다른 사용자가 같은 캠페인 코드를 받았다면** 그 사용자도 매장에서
> 사용 가능합니다 (의도된 동작). 캠페인 = 코드 1개 = 의도된 다중 사용.

### Q4. 같은 본문으로 같은 캠페인을 며칠 나눠 보냈는데 코드가 또 새로 발급?
24시간 안에 **같은 본문 + 같은 카테고리 + 같은 redemptionInfo** 면 이전 코드
자동 재사용 (PR-S9, Build 338+). POS 재등록 불필요.

### Q5. 코드를 잊어버렸어요. 어디서 다시 보나요?
프로필 → "📊 캠페인 인사이트" → "🔑 발급된 매장 코드" 섹션에서 dedup 된 코드
목록 + 복사 버튼.

### Q6. 만료된 캠페인 코드는 POS 에서 어떻게 처리하나요?
"발급된 매장 코드" 화면에서 만료된 코드는 회색 + 줄긋기로 표시. POS 에서
삭제 후 신규 캠페인 발행 권장 (코칭 메시지로 알림).

## 4. 매장 POS 별 설정 위치 (참고)

| POS 시스템 | 등록 메뉴 |
|---|---|
| Smart POS (KIS) | 환경설정 → 쿠폰/할인 → 신규 등록 |
| OK POS | 매출 → 할인 코드 관리 → +추가 |
| Cafe24 POS | 운영 → 프로모션 → 쿠폰 → 새 코드 |
| BAEMIN/Yogiyo POS | 매장관리 → 할인설정 → 코드형 할인 |
| 일반 단말기 (편의점) | 점주 메뉴 → "이벤트 쿠폰" → 등록 |

각 시스템마다 정확한 위치는 다를 수 있으니 POS 공급사 매뉴얼을 함께 참고.

## 5. 문제 발생 시

| 상황 | 원인 | 해결 |
|---|---|---|
| 손님이 코드 노출 했는데 사용 완료 0 | POS 등록 누락 | 점주 확인 — Brand 인사이트의 "코드 노출 0" 코칭 |
| 코드 노출도 0 | 매장 거리 멀거나 사용 시점 안 맞음 | letter 발송 반경 좁히기 |
| 사용 완료율 < 5% | 본문 매력 부족 | 본문 수정 또는 할인율 증대 |
| 사용 완료율 ≥ 20% | 효과 좋음 | 동일 패턴 재집행 |

자동 코칭은 캠페인 인사이트 화면에서 💡 메시지로 노출됩니다.
