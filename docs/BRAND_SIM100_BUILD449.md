Build 448-449 가 고정 매장 위치/정확좌표 발송을 전면에 노출하면서 이 경로 진입이 흔해져 '대량발송했는데 1개만 발송' 사용자 보고와 정확히 일치한다.

(B) 발송 후 부분발송 감지 — compose_screen.dart:1779-1808 성공 경로에서 expected = _bulkTargets.length * _sendPerCountry 를 계산해 totalSent < expected 이면 reveal/성공 스낵바 대신 '요청 {expected}통 중 {totalSent}통만 발송됨 — ExactDrop 크레딧 부족' 경고 스낵바(신규 i18n 키, 14언어) 노출. (C) 선택적으로 app_state.dart sendBrandExpressBlast 가 (sent, requestedCount) 또는 부분발송 플래그를 반환하도록 시그니처 보강해 호출부가 명확히 분기. 1864-1899 일반 bulk 경로(sendBulkLetter)도 동일 정책 점검 권장.
