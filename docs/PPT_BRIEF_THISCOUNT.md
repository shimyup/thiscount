## 슬라이드 1 — 표지
- 제목: **Thiscount (디스카운트)**
- 부제: 지도에서 줍는 동네 할인 — 위치기반 쿠폰 픽업 앱
- 메타: iOS (Flutter) · 2026.06 · Build 461 / TestFlight Build 460 배포 중
- 비주얼 제안: 지도 위 핀+티켓+% 아이콘(앱 아이콘 모티프)

## 슬라이드 2 — 한 줄 컨셉
- 메시지: **"쿠폰을 '받는' 게 아니라 '줍는다'"**
- 동네 매장이 지도 위에 쿠폰을 떨어뜨리고, 소비자는 200m 반경 안에서
  보물찾기처럼 픽업 → 매장에서 코드로 사용
- 차별점 3개 (아이콘 3분할):
  - 🗺 위치 게임화 — 픽업 반경·쿨다운·레어 드롭(✨rare 5% / 💎epic 1%)
  - 🏪 매장 친화 — POS 에 코드 1회 등록이면 끝 (별도 단말기·연동 0)
  - 🔁 풀퍼널 루프 — 발견→방문→재방문(단골 스탬프)→확산(친구 선물)
- 비주얼 제안: 지도 중심 일러스트 + 3 아이콘 카드

## 슬라이드 3 — 3-티어 구조
- 표 또는 3컬럼 카드:
  - **Free**: 지도 픽업(200m, 60분 쿨다운), 수집첩, 기본 경험
  - **Premium**: 쿨다운 없음, 관심 카테고리 필터, 답장, 7일 무료 체험
  - **Brand(매장)**: 캠페인 발송(단건/대량/특급), 자동발송 zone, 할인코드
    발급, ROI 인사이트, AI 쿠폰 생성
- 수익 모델: 구독(Premium/Brand) + ExactDrop 크레딧(정밀 발송 종량제)
- 비주얼 제안: 3단 피라미드 또는 가격표 카드

## 슬라이드 4 — 소비자 경험 (퍼널 흐름도)
- 가로 플로우: 발견(지도 마커) → 픽업(탭) → 사용 진행(바코드/대형 코드,
  화면 밝기 자동↑, 스크린샷 차단) → 사용 완료 → 스탬프 +1 → 5회 완성 시
  💎epic 단골 보상 자동 발급 → 재방문
- 보조 기능: 나침반 힌트(반경 밖 가장 가까운 쿠폰 방향), 만료 임박 알림,
  친구 선물 코드(🎁 수집첩 수령)
- 비주얼 제안: 6단계 가로 타임라인 + 폰 목업 자리

## 슬라이드 5 — 사장(Brand) 경험
- **3스텝 발송 마법사**: ①혜택(AI 생성 버튼) ②범위(매장 위치+반경) ③확인(코드 미리보기)
- **자동발송 zone**: 매장 반경(300m/2km)에 손님이 들어오면 쿠폰 자동 발급
  — Build 461 부터 목록/성과/조기 중단 관리 가능
- **할인코드 운영**: 캠페인 1개 = 코드 1개, POS 1회 등록, 발송 직후 코드
  reveal + 복사
- **ROI 인사이트**: 발송→픽업→노출→사용 4단계 퍼널, 캠페인별 코칭팁,
  재발송 버튼('같은 조건으로 다시 보내기'), 팔로워 KPI
- 비주얼 제안: 좌(마법사 3스텝) / 우(퍼널 막대 그래프)

## 슬라이드 6 — AI 기능 (첫 진짜 AI 구현)
- **AI 쿠폰 생성**: 업종+한 줄 설명 입력 → 카피·혜택 초안 자동 완성 →
  compose 자동 채움 (혜택 생성 시 일반→할인권 자동 승격)
- 스택: Google **Gemini 2.5 Flash**, 서버측 Cloud Function(키 비노출,
  ID토큰 검증 + rate limit), 배포·엔드투엔드 검증 완료
- 의미: 카피 못 쓰는 사장의 진입 장벽 제거 + AI 바우처/지원사업 레버
- 비주얼 제안: 입력→AI→완성 쿠폰 3단 변환 다이어그램

## 슬라이드 7 — 개발 방식: 시뮬레이션 기반 QA
- 메시지: **"수백 명의 가상 사용자가 먼저 써보고 출시한다"**
- AI 멀티에이전트 시뮬레이션 워크플로우: 100~214 시나리오 × 10회 이상
  라운드(일반/브랜드/공격자/페르소나 6관점) → 결함 적대적 검증 → 수정
- 누적 성과(대표): P0(출시차단)~P3 수백 건 발견·수정 — 결제 신뢰, 데이터
  영속, 보안, i18n, 접근성 전반
- 보안 특화: PII 탈취 공격 시뮬레이션(29 공격자 페르소나) → 8건 hardening,
  메일/SMS 키 서버 이전(Cloud Function relay), OTP brute-force 차단
- 비주얼 제안: "시뮬레이션 → 검증 → 수정" 순환 루프 다이어그램 + 숫자 배지
